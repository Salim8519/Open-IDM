Downloads that don't start over.

Peregrine is a free, open-source download manager for Windows and macOS. It splits every file into up to 32 connections and saves progress every second, so a dropped Wi-Fi, a crash or a power cut costs you seconds, not the whole file.

What it actually does

No feature checklist padding. These are the things Peregrine was built around, and each one is covered by tests against a deliberately broken server.

32 connections

Faster on most servers

When one connection finishes, it takes half of the slowest remaining part. All connections stay busy until the last byte.

saved every 1 s

Resume that survives crashes

Progress goes to a crash-safe database. Data is written to .peregrine.part and renamed only after it is verified.

expired links

Paste a fresh link, keep the bytes

When a link expires mid-download, give Peregrine a new one and it carries on from where it stopped. It also notices when the file on the server changed.

Chrome · Edge · Brave · Opera · Vivaldi

Catches downloads in the browser

The extension hands downloads over with their cookies, so files behind a login work too. It also finds videos on the page.

magnet · .torrent · HLS · DASH · FTP

More than plain HTTP

Torrents (nothing is seeded after you finish), streaming video saved as one file, and FTP.

16 languages

Including full right-to-left

Arabic, Persian and Urdu get a real RTL layout, not mirrored English. Light and dark themes.

Also a command-line tool

The same engine, for scripts and servers on Windows, macOS and Linux. Run the same command again and it resumes.

# 16 connections, capped at 5 MB/s
peregrine get https://example.com/big.iso -o ~/Downloads -c 16 --limit 5M

# send a link to the desktop app instead
peregrine add https://example.com/file.zip
peregrine list

No ads. No tracking. No account.

Peregrine makes no network requests except the downloads you start. Filenames from servers are cleaned against path tricks, downloaded files get the operating system's "from the internet" mark, and the local API only listens on 127.0.0.1 behind a secret token. Read the threat model. This website has no analytics either.

Questions

Is Peregrine really free?

Yes. It is open source under GPL-3.0. There is no paid version, no trial, no ads and no bundled offers.

Is it a good alternative to IDM?

It does the core things people use IDM for: many connections per file, resuming broken downloads and catching downloads from the browser. It is free, open source and also runs on macOS. It is an early preview, so expect rough edges and report them.

Why does Windows SmartScreen warn me?

The builds are not code-signed yet. Click More info → Run anyway. Check the file against SHA256SUMS.txt if you want to be sure it is the real one.

Does it work on Linux?

On Linux, Peregrine is a command-line tool for x64 and ARM64. The desktop app is for Windows and macOS.

Does it collect any data?

No. No analytics, no telemetry. It only connects to the internet for the downloads you start.

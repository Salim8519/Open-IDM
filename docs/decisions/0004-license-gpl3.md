# 0004 — License: GPL-3.0

- Status: accepted (maintainer asked Claude to decide and publish, 2026-11-13)
- Date: 2026-11-12

## Context
The app must stay free forever; we don't want closed-source forks bundling ads.

## Decision
License the project under GPL-3.0-or-later.

## Alternatives considered
- MIT / Apache-2.0 — maximum reuse, but allows closed, ad-laden forks.

## Consequences
- Forks must stay open source.
- Dependencies must be GPL-compatible (MIT, BSD, Apache-2.0, MPL-2.0 are fine).
- Fits F-Droid distribution.
